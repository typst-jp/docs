# バージョン0.1.0（2023年4月4日）

## 破壊的変更
- CLIを使用する場合、サブコマンドが必要になりました。
  - PDFを作成するには`typst compile file.typ`または`typst c file.typ`を使用します。
  - コンパイルして変更を監視するには`typst watch file.typ`または`typst w file.typ`を使用します。
  - 全てのフォントを一覧表示するには`typst fonts`を使用します。
- 手動で更新するカウンターはゼロから始まるようになりました。詳細は、[こちら]($counter)の「インクリメント方法」セクションをお読みください。
- [参考文献のスタイル]($bibliography.style)の`{"author-date"}`と`{"author-title"}`を`{"chicago-author-date"}`と`{"chicago-author-title"}`にリネームしました。

## 図表の改善
- 図表はコンテンツを自動的に検出し、それに応じて動作を調整するようになりました。例えば、表を含む図表には自動的に「Table X」という接頭辞が付き、別のカウンターが使用されます。
- 図表の補足語（「Figure」や「Table」など）をカスタマイズできるようになりました。
- さらに、showルールで自動的に決定された種類、補足語、カウンターにアクセスできるため、図表を完全にカスタマイズできるようになりました。

## 参考文献の改善
- [`bibliography`]($bibliography)が複数の参考文献のパスも配列として受け取るようになりました。
- BibLaTeXファイルのパースで許容される形式が増えました。版、ページ、巻、日付の数値以外の値と、Jabref形式のコメントを受け付けるようになり、略語のパースも修正しました。
- ラベルと参照に、末尾を除いて`:`と`.`を含められるようになりました。
- APAスタイルでの参考文献の順序を修正しました。

## 描画機能の追加
- 多角形を描画するための[`polygon`]($polygon)関数を追加しました。
- [ボックス]($box.clip)と[ブロック]($block.clip)でクリッピングをサポートしました。

## コマンドラインインターフェース
- エラーが発生した場合、ゼロ以外のステータスコードで終了するようになりました。
- 現在のディレクトリではなく、ルートディレクトリを監視するようになりました。
- デフォルトで入力ファイルの隣にPDFファイルを出力するようになりました。
- より多くの種類の入力ファイル（`/dev/stdin`など）を受け付けるようになりました。
- PDFを直接開くための`--open`フラグを追加しました。

## その他の改善
- YAMLファイルからデータを読み込むための[`yaml`]($yaml)関数を追加しました。
- さらにいくつかの言語（IT、RU、ZH、FR、PT）で基本的な国際化をサポートしました。
- ヘブライ語の番号付けをサポートしました。
- 2、8、16進数の[整数]($int)をサポートしました。
- 二重角括弧とラプラス演算子の記号を追加しました。
- [`link`]($link)関数が[ラベル]($label)を受け取るようになりました。
- リンクの構文でより多くの文字を使用できるようになりました。
- 日本語と中国語の文章の均等割り付けを改善しました。
- 計算結果が実数でない場合の計算関数の動作が、より一貫するようになりました。
- 非推奨の山括弧を置き換えました。
- 関数呼び出しの最大深度を256から64に減らしました。
- スタイル設定された文章で段落が始まる場合に、[`first-line-indent`]($par.first-line-indent)が適用されない問題を修正しました。
- 数式の単項演算子での余分な間隔を修正しました。
- `{block(above: 1cm, below: 1cm, ..)}`などでのブロックの間隔を修正しました。
- 数式のテキスト演算子のスタイル設定を修正しました。
- バッククォートが1つのrawブロックで、言語タグを誤ってパースする問題を修正しました。
- カウンターと状態の表示に関するバグを修正しました。
- ページカウンターに関連するクラッシュを修正しました。
- [`symbol`]($symbol)関数を引数なしで呼び出した場合のクラッシュを修正しました。
- 参考文献の生成時のクラッシュを修正しました。
- 特定のコンテンツ要素のラベルへのアクセスを修正しました。
- CSVのパース時のエラーメッセージに表示される行番号を修正しました。
- 特定のマークアップ要素の後で自動補完が正しく動作しない問題を修正しました。
