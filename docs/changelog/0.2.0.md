# バージョン0.2.0（2023年4月11日）

## 破壊的変更
- [forループ]($scripting/#loops)でインデックスと値を反復処理するサポートを削除しました。代わりに、分割と列挙を使用します。[`map`]($array.map)メソッドも同様です。
- [辞書]($dictionary)を反復処理する順序が、アルファベット順から挿入順に変わりました。

## 新機能
- letバインディングに[分割構文]($scripting/#bindings)を追加しました。これにより、`{let (1, 2) = array}`のように書けるようになりました。
- [`enumerate`]($array.enumerate)メソッドを追加しました。
- Bézierパスを描画するための[`path`]($path)関数を追加しました。
- 周囲のページやコンテナーのサイズにアクセスするための[`layout`]($layout)関数を追加しました。
- [`sorted`]($array.sorted)メソッドに`key`パラメーターを追加しました。

## コマンドラインインターフェース
- `--open`フラグがプログラムの処理をブロックする問題を修正しました。
- New Computer Modernフォントがバイナリへ埋め込まれるようになりました。
- 環境変数`GEN_ARTIFACTS`に出力先のディレクトリを設定してからTypstをビルドすることで、シェル補完とmanページを生成できるようになりました。

## その他の改善
- アウトライン内のページの番号付けを修正しました。
- さらにいくつかの言語（AR、NB、CS、NN、PL、SL、ES、UA、VI）で基本的な国際化に対応しました。
- いくつかの番号付けパターン（いろは順、中国語）を追加しました。
- `sinc`[演算子]($math.op)を追加しました。
- [`hide`]($hide)で数式を非表示にできないバグを修正しました。
- ボックス、ブロック、図形のサイズに関する問題を修正しました。
- いくつかの翻訳を修正しました。
- [`cal`]($math.cal)と[`frak`]($math.frak)のスタイルで「R」の字形が入れ替わっていた問題を修正しました。
- 数式のスタイル設定に関するいくつかの問題を修正しました。
- 見出しへの参照の補足語を修正しました。
- 特定の状況での識別子のシンタックスハイライトを修正しました。
- [比率]($ratio)をより多くの型と乗算できるようになりました。また、[`float`]($float)関数で[浮動小数点数]($float)に変換できます。
