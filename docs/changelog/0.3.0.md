# バージョン0.3.0（2023年4月26日）

## 破壊的変更
- いくつかの記号の名前を変更しました。以前の`dot.op`は単に`dot`に、基本のドットは`dot.basic`になりました。`ast`と`tilde`も同様です。
- 動作をより正確に反映するため、`mod`の名前を[`rem`]($calc.rem)に変更しました。猶予期間として、次の更新までは`mod`として引き続き利用できます。
- 単独のアンダースコアは有効な識別子ではなくなり、パターン内でのみ使用できるようになりました。
- [`query`]($query)から`before`と`after`引数を削除しました。代わりに、柔軟な[セレクター]($selector)のコンビネーターメソッドを使用します。
- ベースとなる記号の前に置かれる[アタッチメント]($math.attach)（下付き文字、上付き文字）に対応しました。`top`と`bottom`引数の名前を`t`と`b`に変更しました。

## 新機能
- より複雑な[ストローク]($stroke)（キャップ、接合、破線パターンを設定可能）に対応しました。
- 数式用の[`cancel`]($math.cancel)関数を追加しました。
- 引数リストと代入で[分割]($scripting/#bindings)ができるようになりました。
- image関数に代替テキストの[`alt`]($image.alt)引数を追加しました。
- TOMLファイルからデータを読み込むための[`toml`]($toml)関数を追加しました。
- 配列用の[`zip`]($array.zip)、[`sum`]($array.sum)、[`product`]($array.product)メソッドを追加しました。
- `fact`、`perm`、`binom`、`gcd`、`lcm`、`atan2`、`quo`、`trunc`、`fract`の[計算]($category/foundations/calc)関数を追加しました。

## 改善
- SVG内のテキストが正しく表示されるようになりました。
- TypstがPDFの見出しアウトラインを生成するようになりました。
- [参照]($ref)がshowルールで参照先の要素をフィールドとして提供するようになりました。
- 中国語の均等割り付けを改善するため、改行アルゴリズムを改良しました。
- ロケーションが有効なセレクターの一種になりました。
- 代数用の記号をいくつか追加しました。
- スペイン語のスマートクォートを追加しました。
- セレクターのような値をセレクターに変換する[`selector`]($selector)関数を追加しました。変換後のセレクターでは、コンビネーターメソッドを呼び出せます。
- 一部のエラーメッセージを改善しました。
- アウトラインと参考文献の見出しをshow-setルールでスタイル設定できるようになりました。
- 数値に対する演算が、オーバーフローする代わりにエラーを出すようになりました。

## バグ修正
- インライン数式や引用、その他の要素に続く句読点の前で誤って改行される問題を修正しました。
- [引数シンク]($arguments)のバグを修正しました。
- 太さがゼロのストロークの問題を修正しました。
- 数式における非表示とshowルールの処理を修正しました。
- 行列の配置を修正しました。
- 数式の配置に関するいくつかのバグを修正しました。
- グリッドのセルの配置を修正しました。
- グローバルな配置設定がある場合に、箇条書きリストと番号付きリストのマーカーの配置を修正しました。
- [パス]($path)を閉じる処理を修正しました。
- 図表の参照時に発生するコンパイラーのクラッシュを修正しました。
- 文章と同様、数式でも末尾の単一の改行が無視されるようになりました。

## コマンドラインインターフェース
- フォントパスとコンパイルルートは、環境変数`TYPST_FONT_PATHS`と`TYPST_ROOT`で設定できるようになりました。
- `typst fonts`の出力に埋め込みフォントが含まれるようになりました。

## 開発
- デバッグと最適化のためのインストルメンテーションを追加しました。
- テストの参照画像を更新するための`--update`フラグと`UPDATE_EXPECT`環境変数を追加しました。
- `--subtest`で特定のサブテストを実行できるようになりました。
- テストが複数のスレッドで実行されるようになりました。
